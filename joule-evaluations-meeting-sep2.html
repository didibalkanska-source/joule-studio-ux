Overview

Evgeny demonstrated the Agent Evaluations feature in both the existing UI and the new V2 representation. A key blocker — authorization between the agent gateway and AI Core — was resolved by Gaurav with a temporary fix, meaning evaluations can now run end-to-end. The session surfaced a number of open product and UX questions that require PM decisions before the feature can ship.
