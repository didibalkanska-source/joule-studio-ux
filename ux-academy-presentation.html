Blueprint: The Audience
Main Target: User Assistants to become UX specialists
Jordan Chen
User Assistance Specialist
"Jordan was offered the opportunity to reskill into a UX Specialist role as part of the company's internal mobility program. The company recognized that user assistance specialists have valuable user insights and customer empathy that could strengthen the UX team."
Goals
  • Transition into a UX designer or UX researcher role
  • Learn how to translate user problems into design solutions
  • Understand the full UX process from research to testing
  • Gain practical experience with UX tools and methods
  • Contribute earlier in the product development lifecycle
Learning Styles
  • Prefers practical examples over theory
  • Learns best through hands-on exercises and real projects
  • Benefits from mentorship and feedback
  • Engages with short learning modules (videos, articles)
  • Likes collaborative learning and discussion
Pain Points & Challenges
  • Unsure how to move from documentation → UX design
  • Limited experience with design tools and prototyping
  • Difficulty understanding how research insights turn into design solutions
  • UX concepts sometimes feel theoretical and disconnected
  • Not always confident speaking the language of UX designers
Learning Needs
  • Clear understanding of UX methods and workflows
  • Hands-on practice with UX tools (Figma, research tools)
  • Guidance on how research insights translate into design decisions
  • Real examples of UX work in enterprise environments
  • Opportunities to apply learning in a project

Learning Objectives
Learning Objectives
By the end of the training, participants will be able to:

Conduct and synthesize user research using at least 3 different methods appropriate to common design challenges

Transform support insights into UX deliverables such as user personas, journey maps, and problem statements

Create wireframes and prototypes using industry-standard tools (Figma)

Translate individual user problems into systemic design opportunities that address root causes

Create designs for applications utilizing SAP Design System

Access learning tools for further growth — mentorship programs, UX groups, and become part of a community
